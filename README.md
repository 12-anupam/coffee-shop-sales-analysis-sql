# ☕ Coffee Shop Sales Analysis (SQL Project)

## 📌 Project Overview
This project analyzes coffee shop sales data using SQL to uncover business insights related to sales performance, customer behavior, and product trends.

The goal is to simulate real-world business analysis using structured SQL queries.

---

## 🧹 Data Preparation
- Cleaned and formatted date & time columns  
- Standardized column data types  
- Ensured consistency across transactional data  

---

## 📊 KPI Analysis
- Total Sales by Month  
- Total Orders by Month  
- Total Quantity Sold  
- Month-on-Month (MoM) Growth Analysis  

---

## 📈 Business Insights

### 🔹 Time-Based Analysis
- Monthly sales trends  
- Daily sales performance  
- Hourly sales distribution  
- Weekday vs Weekend comparison  

### 🔹 Store & Product Analysis
- Sales by store location  
- Product category performance  
- Top 10 best-selling products  

### 🔹 Customer Behavior Insights
- Sales vs average performance (Above/Below Average days)  
- Order patterns across time  

---

## 🧠 Advanced SQL Concepts Used
- Window Functions (LAG, OVER)  
- Aggregate Functions (SUM, AVG, COUNT)  
- CASE WHEN logic  
- Date & Time functions  
- Subqueries  

---

## 🛠️ Tools Used
- SQL (MySQL)
- Data Analysis

---


## 🎯 Key Learnings
- Time-series analysis using SQL  
- Business KPI development  
- Advanced SQL query writing  
- Translating raw data into insights
